# StudentScope 🎓

### Student Performance Analysis & Prediction System

StudentScope is a machine learning-based web application that analyzes student performance and predicts final grades using academic and personal factors.

## ✨ Features

* Interactive student performance dashboard
* Student data analysis and visualization
* Final grade prediction using Machine Learning
* Model evaluation metrics and feature importance
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript, Chart.js
* **Backend:** Python, Flask
* **Data Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-learn
* **Model Storage:** Joblib / Pickle

## 🤖 Machine Learning Model

The application uses a trained regression model to predict students' final grades (G3) based on selected academic and personal factors.

## 📁 Project Structure

* `index.html` – Webpage structure
* `style.css` – Website styling
* `script.js` – Frontend functionality
* `app.py` – Flask application and API
* `train_model.py` – Model training script
* `student.csv` – Dataset
* `student_model.pkl` – Trained model
* `model_metrics.json` – Model evaluation metrics
* `requirements.txt` – Python dependencies

## 🚀 Getting Started

1. Clone or download this repository.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Run the Flask application:
   `python app.py`
4. Open the local URL displayed in your terminal.

## 🎯 Project Goal

To explore student performance through data analysis and machine learning and provide insights that may help identify factors associated with academic outcomes.
